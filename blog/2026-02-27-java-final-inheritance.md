## 1. Eclipse 프로젝트 & 코드 관리

프로젝트가 많아지면 탐색기가 복잡해지고 메모리도 점유되므로, 사용하지 않는 프로젝트는 닫아두는 것이 좋다.

| 작업 | 경로 | 효과 |
|------|------|------|
| 프로젝트 닫기 | 우클릭 → Close Project | 비활성화, 메모리 절약 |
| 닫힌 프로젝트 숨기기 | 탐색기(점 3개) → Filters → Closed Projects 체크 | 목록에서 안 보임 |
| 다시 열기 | 탐색기에서 더블클릭 | 재활성화 |

### 코드 포맷팅

```
우클릭 → Source → Format
단축키: Ctrl + Shift + F
```

팀 단위 개발에서 포맷 미적용 코드는 리뷰 품질을 저하시키므로 습관화가 필요하다.

**핵심 키워드:** `Eclipse` `Close Project` `Filters` `Format` `메모리 관리`

## 2. final의 3가지 적용 지점

final은 "어디에 붙이느냐"에 따라 제약 대상이 달라진다.

| 적용 대상 | final 의미 | 핵심 효과 |
|----------|-----------|----------|
| 변수 | 상수화 | 최초 1회만 값 결정, 재대입 불가 |
| 메소드 | 재정의(override) 불가 | 자식 클래스가 구현을 바꿀 수 없음 |
| 클래스 | 상속 불가 | extends로 확장 불가 |

:::info
- **확장(extends)**: 부모 기능을 물려받아 범위를 넓히는 것
- **재정의(override)**: 부모의 동작을 자식이 동일한 시그니처로 바꿔 끼우는 것

final은 이 두 가능성을 명시적으로 차단한다.
:::

**핵심 키워드:** `final` `변수` `메소드` `클래스` `상속`

## 3. final 변수 — 초기화와 재대입 금지

final 변수는 **단 한 번만 값을 결정**할 수 있다. 이후 재대입 시 컴파일 오류 발생.

### 변수 종류별 정리

| 변수 종류 | 선언 위치 | 접근/특징 |
|----------|----------|----------|
| 인스턴스 변수 | 클래스 내부(필드) | 객체를 통해 접근, 생성 시 초기화 |
| 지역 변수(로컬) | 메소드 내부 | 메소드 밖에서 직접 접근 불가, return으로 전달 |
| 정적 변수(static) | 클래스 내부(필드) | 클래스명으로 접근, 메모리에 1회 로딩 후 공유 |

### 코드 예시

```java
public class FinalClass {
    public static final int AGE = 10;  // 선언과 동시에 초기화

    public static final int[] ARR;
    static {
        ARR = new int[3];  // 정적 초기화 블록에서 초기화
    }
}
```

```java
final int a = 10;
a = 20;  // 컴파일 오류 — 이미 값이 지정됨
```

:::warning
멤버필드에 final을 선언하면 반드시 선언 시점 또는 정적 초기화 블록(`static {}`)에서 값을 채워야 한다. 비어있으면 컴파일 오류.
:::

**핵심 키워드:** `상수` `초기화` `static 블록` `로컬 변수` `재대입`

## 4. final 메소드 — 오버라이드 차단

부모 메소드가 final이면 자식 클래스에서 재정의할 수 없다. 호출을 통한 사용만 허용된다.

| 부모 메소드 상태 | Override 목록 노출 | 자식 재정의 가능 여부 |
|----------------|-------------------|-------------------|
| 일반 메소드 | 노출됨 | 가능 |
| final 메소드 | 노출 안 됨 | 불가 |

```java
String msg = child.callMessage();  // 반환값은 변수에 받거나 출력 함수로 전달해야 함
System.out.println(msg);
```

:::info
반환 타입이 있는 메소드는 호출만 한다고 출력이 자동으로 발생하지 않는다.
반환값을 사용하려면 반드시 변수에 받거나 출력 함수로 전달해야 한다.
:::

**핵심 키워드:** `override` `final 메소드` `상속` `반환 타입` `Source 메뉴`

## 5. final 클래스 — 상속 금지

final 클래스는 다른 클래스의 부모가 될 수 없다.

```java
final class X {}
class Y extends X {}  // 컴파일 오류
```

대표 사례: `String` 클래스는 final로 선언되어 있어 상속이 불가하다. 문자열 동작을 임의로 변형하는 상황을 방지하기 위한 설계다.

| 구분 | 의미 |
|------|------|
| final 클래스 | 확장 구조 고정 — 상속 불가 |
| final 메소드 | 동작 고정 — 재정의 불가 |
| final 변수 | 값 고정 — 재대입 불가 |

**핵심 키워드:** `final 클래스` `String` `타입 안정성` `상속 금지` `불변성`
