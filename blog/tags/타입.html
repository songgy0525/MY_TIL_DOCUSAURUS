🗺 오늘 배운 흐름 한눈에 보기​

전일 복습 → JAR 패키징 → 기본 타입/리터럴 → 실수/캐스팅
→ char/boolean → var → 변수 종류/스코프 → DTO → 연산자 → char 변환

1️⃣ 전일 복습 — 클래스와 객체​

  • 설계도 = 클래스, 사용 = 객체(인스턴스)
  • main()이 있는 클래스에서만 실행 가능
  • 요구사항에 맞춰 최소 단위로 구현하는 습관이 중요
Student s = new Student();
System.out.println(s.name);
System.out.println(s.age);

핵심 키워드: 클래스 인스턴스화 필드 main System.out.println

2️⃣ JAR 패키징과 Runnable JAR 실행​

JAR(Java Archive)는 소스가 아닌 실행/배포를 위해 결과물을 묶는 패키징 산출물이다.

형식용도
JAR일반 자바 앱 배포
WAR웹 앱 배포 (서블릿 컨테이너 필요)
Spring Boot JAR내장 서버 포함, 단독 실행 가능

Runnable JAR 생성 순서​

  1. Java Project 생성 후 패키지(3단위 이상) + 메인 클래스 생성
  2. Run As > Java Application 으로 한 번 실행 (Launch configuration 등록)
  3. 프로젝트 우클릭 → Export > Runnable JAR file 선택
  4. Destination 경로/파일명 지정 후 Finish
  5. 터미널에서 실행
java -jar 파일명.jar
정보

터미널 명령어 차이:

  • Windows CMD: DIR
  • Linux/Mac 터미널: ls

핵심 키워드: JAR Runnable JAR Manifest Export java -jar

3️⃣ 기본 타입(Primitive)과 리터럴​

자바 기본 타입은 8가지다.

분류타입핵심 포인트
정수형byte, short, int, long크기에 따라 범위 다름
실수형float, double부동소수점, 기본 리터럴은 double
문자형char유니코드 기반, 숫자처럼 연산 가능
논리형booleantrue/false, 0/1 치환 불가

정수 리터럴 표기법​

표기예시의미
10진수10일반 숫자
16진수0xFHEX
8진수07OCT
2진수0b10Binary
경고

정수 리터럴 기본 = int, 실수 리터럴 기본 = double

작은 그릇(float)에 큰 리터럴(double)을 담으면 타입 미스매치 오류 발생!

핵심 키워드: Primitive 리터럴 int 기본 double 기본 유니코드

4️⃣ 실수(부동소수점)와 캐스팅​

float에 실수 리터럴 대입 시 기본이 double이라 오류 발생 → F 접미사 또는 명시적 캐스팅 필요

float f1 = 3.14F;          // F 접미사
float f2 = (float) 3.14;   // 명시적 캐스팅
double d1 = 3.14;
double d2 = 3e2;           // 지수 표기법: 3 × 10² = 300.0
정보

연산 결과는 참여하는 타입 중 더 큰 타입으로 승격된다. 금융 도메인 등 정밀도가 중요한 곳에서는 타입 선택과 오차 관리가 핵심이다.

핵심 키워드: 부동소수점 float double 캐스팅 지수표기법

5️⃣ char, boolean의 특징​

char — 유니코드 기반​

char c1 = 'A';
char c2 = '\u0041';  // 'A' 와 동일
  • 연산에 참여하면 정수로 승격 → 다시 문자로 바꾸려면 캐스팅 필요

boolean​

boolean b = true;
// boolean b = 1;  ← 자바에서는 불가! (다른 언어와 다름)
경고

자바의 boolean은 true/false 키워드만 사용 가능. 다른 언어처럼 0/1로 자동 변환되지 않는다.

핵심 키워드: char 유니코드 \u boolean true/false

6️⃣ var (자바 10+) — 타입 추론​

var n = 10;                              // int로 추론
var list = new java.util.ArrayList<String>();  // 타입 반복 생략
정보

var는 동적 타입이 아니다! 초기 할당으로 타입이 결정된 후 고정 → 이후 다른 타입 대입 불가

  • 로컬 변수 선언에서만 사용 가능
  • 제네릭 컬렉션 생성 시 반복되는 타입 선언을 줄여 가독성 향상

핵심 키워드: var 타입추론 로컬변수 제네릭 가독성

7️⃣ 변수 종류와 스코프​

구분선언 위치자동 초기화접근 방식
로컬 변수메소드 내부❌ (미초기화 시 컴파일 오류)메소드 내부에서만 사용
인스턴스 변수멤버필드✅ (타입 기본값)obj.field
static 변수멤버필드 + static✅ (앱 시작 시 로딩)ClassName.field 권고
this.field   // 멤버필드 명시적 접근 (로컬 변수와 이름 충돌 시)
ClassName.staticField  // static은 클래스명으로 접근 권고
경고

로컬 변수가 멤버필드와 같은 이름이면 로컬이 우선 (멤버필드를 가림)

멤버필드를 명시하려면 this. 사용!

위험

static을 남발하면 공유 상태로 추적이 어렵고, 앱 종료까지 메모리에 유지된다. 필요한 공용 기능/상수 수준에서만 제한적으로 사용할 것.

핵심 키워드: 로컬변수 인스턴스변수 static this 스코프

8️⃣ DTO와 단일 반환​

자바는 반환값이 1개만 가능 → 여러 값을 반환해야 할 때 DTO를 사용한다.

// DTO 클래스
class InfoUserDTO {
    String name;
    int age;
}

// 메소드에서 DTO 반환
InfoUserDTO getUser() {
    InfoUserDTO dto = new InfoUserDTO();
    dto.name = "경용";
    dto.age = 25;
    return dto;
}
정보

코드 탐색 팁

  • F3 또는 Ctrl + 클릭 → 선언 위치로 이동
용어의미
파라미터 (Parameter)메소드가 전달받는 값을 담는 변수
아규먼트 (Argument)메소드 호출 시 전달하는 실제 값

핵심 키워드: DTO 반환타입 파라미터 아규먼트 static 접근

9️⃣ 연산자 총정리​

산술 연산 주의점​

int result = 5 / 2;       // 2 (정수끼리 나누면 몫만)
float f = 5 / 2;          // 2.0 (연산은 정수, 저장만 float)
float f2 = 5 / 2.0F;      // 2.5 (실수가 참여해야 실수 결과)
long l = 10L;             // L 접미사 = long 리터럴

대입 연산 주의​

i += 5;   // 올바른 단축 대입
i =+ 5;   // 주의! 양수 표시로 해석됨 (+=와 다름)

비트 연산​

5 & 4   // 0101 & 0100 = 0100 = 4
5 | 4   // 0101 | 0100 = 0101 = 5

숏서킷 (Short-circuit)​

연산자동작
&&앞이 false면 뒤 평가 생략
||앞이 true면 뒤 평가 생략
&, |앞 결과 무관하게 뒤까지 모두 평가
정보

연산자 우선순위 — 전체 암기보다 괄호가 최우선이라는 원칙만 기억하자.

IDE의 노란 언더라인은 컴파일 오류가 아닌 품질 경고 (사용 안 된 변수, 무의미한 표현 등)

핵심 키워드: 모듈러스 캐스팅 증감연산자 비트연산 숏서킷

🔟 char → 숫자 변환​

char c = '9';

int wrong = (int) c;              // 57 (유니코드 코드포인트)
int correct1 = c - '0';           // 9 ('0' 코드포인트를 빼면 실제 숫자)
int correct2 = Character.getNumericValue(c);  // 9 (API 활용)
정보

'9'를 int로 캐스팅하면 57 (유니코드 코드포인트)이 나온다.

실제 숫자 값을 얻으려면 - '0' 또는 Character.getNumericValue() 사용!

핵심 키워드: char 캐스팅 유니코드 Character.getNumericValue 리터럴 타입연산

✅ 오늘의 핵심 요약​

  1. JAR = 실행 가능한 배포 산출물, java -jar로 실행
  2. 정수 리터럴 기본 = int, 실수 리터럴 기본 = double
  3. float에 실수 넣으려면 F 접미사 또는 (float) 캐스팅
  4. boolean은 true/false만, 0/1 치환 불가
  5. var는 타입 추론이지 동적 타입이 아님 — 한 번 결정되면 고정
  6. 로컬 변수는 자동 초기화 ❌, 멤버필드는 자동 초기화 ✅
  7. &&/|| = 숏서킷, &/| = 전체 평가
  8. '9' → int 캐스팅하면 57, 실제 숫자 9를 원하면 - '0'
