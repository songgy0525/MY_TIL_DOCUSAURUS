## 5️⃣ JDK 다운로드와 매뉴얼 설치

과정 표준은 **Amazon Corretto 21** (오픈소스 배포판).

:::warning
Windows에서는 `C:\Java` 처럼 **공백 없는 루트 경로**에 설치할 것.
`Program Files`는 공백이 포함되어 있어 스크립트/외부 시스템에서 오동작할 수 있다.
:::

**JDK 폴더 구조**

| 디렉터리 | 역할 |
|---------|------|
| `bin` | java, javac 등 실행 명령 바이너리 |
| `lib` | 실행에 필요한 라이브러리 리소스 |
| `conf` | 런타임 동작 설정 파일 |

**핵심 키워드:** `Amazon Corretto` `매뉴얼설치` `bin` `lib` `conf`

## 6️⃣ JAVA_HOME 환경변수 설정

`JAVA_HOME`은 자바 기반 소프트웨어가 JDK 위치를 공통 참조하는 표준 환경변수다.

```cmd
echo %JAVA_HOME%
```

:::warning
- 값은 JDK 루트 폴더까지만 (bin 포함 ❌)
- **시스템 변수**로 설정해야 전체 계정/프로세스에 적용됨
- 설정 후 CMD를 새로 열어야 반영됨
:::

**핵심 키워드:** `JAVA_HOME` `시스템변수` `echo` `CMD` `표준환경`

## 7️⃣ PATH 환경변수 설정과 검증

`Path` 시스템 변수에 `%JAVA_HOME%\bin` 추가 → 어디서든 `java` 명령 실행 가능

```cmd
java -version
```

**자주 겪는 문제**

| 증상 | 원인 | 조치 |
|------|------|------|
| `java -version`이 1.8로 출력 | Path 상단에 기존 JDK 경로 우선 적용 | 기존 Oracle JDK 경로 삭제 또는 순서 조정 |
| `echo %JAVA_HOME%`이 문자열 그대로 출력 | 환경변수 미적용 | 시스템 변수 재등록 후 창 모두 닫고 CMD 재실행 |
| Mac에서 확인 방법 다름 | Unix 계열은 `$VAR` 표기 | `echo $JAVA_HOME` 으로 확인 |

**핵심 키워드:** `PATH` `우선순위` `java -version` `중복JDK` `CLI`

## 9️⃣ 자바 기본 구조와 실행 흐름

| 요소 | 의미 | 핵심 규칙 |
|------|------|----------|
| 클래스 | 값/기능의 묶음, 타입이 됨 | `public` 클래스명 = 파일명 일치 |
| 메소드 | 기능의 단위, 호출로 실행 | 반환 타입 있으면 `return` 필요 |
| `main` | 프로그램 시작점 | `public static void main(String[] args)` |
| 호출 | 점(`.`)으로 하위 멤버 접근 | 객체 인스턴스가 있어야 호출 가능 |

:::info
자바는 **컴파일 언어** — 메소드 정의 순서는 실행과 무관하다.
HTML처럼 위에서 아래로 즉시 해석되는 인터프리터 방식과 다르다.
:::

**핵심 키워드:** `main메소드` `클래스명규칙` `컴파일` `System.out.println` `API`

## 🔟 변수, 타입, 대입, 인스턴스화

```java
int n = 10;           // 대입: 오른쪽 값을 왼쪽 변수에 저장
String s = "hello";   // 참조 타입
Coffee c = new Coffee(); // 인스턴스화: 클래스를 메모리에 올려 객체 생성
```

- 기본 타입: 언어가 미리 정의한 타입 (`int`, `char`, `boolean` 등)
- 참조 타입: `new` 등으로 생성되는 복합 구조
- 오류(빨간 줄) = 문법/타입/세미콜론/반환 등 규칙 위반 → **반드시 해결 후 진행**

**핵심 키워드:** `변수` `데이터타입` `대입연산자` `new` `인스턴스화`

## 1️⃣1️⃣ 커피 예제로 보는 클래스/메소드/객체

```java
Machine m = new Machine();
Coffee c = m.order();
System.out.println(c.name);
System.out.println(c.sugar);
```

| 클래스 | 역할 | 포함 요소 |
|--------|------|----------|
| `Coffee` | 값을 담는 클래스 (POJO) | `String name`, `String sugar` 등 필드 |
| `Machine` | 기능 중심 클래스 | `public Coffee order()`, `private Coffee make()` |
| `CoffeeMain` | 실행 시작점 | `main`에서 객체 생성 및 출력 |

:::warning
자주 나오는 오류들:
- 세미콜론 누락
- 파일명/클래스명 불일치
- `println` 오타 (`IN` / `LN` 구분)
- `System.err` 잘못 사용
:::

**핵심 키워드:** `POJO` `반환타입` `메소드호출` `객체생성` `실행흐름`

## 1️⃣2️⃣ 접근 제어자

| 제어자 | 접근 범위 | 한 줄 정리 |
|--------|----------|----------|
| `public` | 전체 공개 | 모든 패키지/클래스에서 접근 가능 |
| `private` | 내부 전용 | 선언한 클래스 내부에서만 접근 가능 |
| `protected` | 상속 범위 | 자식 클래스에서 접근 가능 |
| `default` | 패키지 범위 | 같은 패키지 소속에서만 접근 가능 |

:::info
모든 자바 클래스는 기본적으로 `extends Object`를 포함한다.
자동완성에서 보이는 `notify`, `hashCode` 등은 **Object로부터 상속된 기능**이다.
:::

**핵심 키워드:** `public` `private` `protected` `default` `패키지`

## 1️⃣3️⃣ 파라미터 vs 아규먼트

```java
void order(int money) {  // money는 파라미터
    System.out.println(money);
}
order(100);  // 100은 아규먼트
```

- **파라미터**: 메소드 선언부의 입력 변수
- **아규먼트**: 호출 시 실제로 전달하는 값

**핵심 키워드:** `파라미터` `아규먼트` `메소드` `입력값` `용어구분`

```java
// 단줄 주석
```

**핵심 키워드:** `주석` `예약어` `UTF-8` `EUC-KR` `인코딩`

## ✅ 오늘의 핵심 요약

1. JDK는 **Amazon Corretto 21 LTS**, 공백 없는 경로에 수동 설치
2. `JAVA_HOME` → JDK 루트 경로 (bin 미포함), 시스템 변수로 설정
3. `PATH` → `%JAVA_HOME%\bin` 추가, 기존 JDK 경로 중복 주의
4. Eclipse는 **Package(압축)** 방식, `eclipse.ini`에서 JDK 명시 연결
5. 자바는 **파일명 = 클래스명**, `main`이 없으면 실행 불가
6. `new` = 인스턴스화, `.` = 멤버 접근, `=` = 오른쪽 값을 왼쪽에 저장
7. AI 쓸 때는 **주제 분리 + 역할 부여** 먼저
